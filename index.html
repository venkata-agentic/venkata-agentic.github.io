JobPilot

An AI agent that does the research phase of a job search and leaves the decisions to me.

Every weekday it searches for my target roles, reads each posting in full, evaluates the fit against my background, and writes a report explaining what it recommends and why. It runs unattended through Claude Code on a schedule.

It can research on its own. It cannot apply.
That boundary is intentional.

AI capability without losing control

Many agent demos focus on what the model can do. I'm just as interested in what it should not do. JobPilot runs under explicit constraints:

  • It can write only to one approved folder. Every other tool is denied.
  • It never submits an application.
  • Judgment calls, like work-authorization questions, come back to me marked "needs my answer".
  • Unknown information stays unknown. It leaves a field empty rather than guess.
  • It uses only job sources that allow automated access.

A trustworthy AI system needs boundaries as much as capabilities.
