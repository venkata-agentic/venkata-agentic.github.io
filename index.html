What I'm building

JobPilot, a job-search agent on Claude

Every weekday it searches Indeed for program and AI-delivery roles in Canada, the US and India, reads each posting in full, keeps the ones that fit my background, and writes a report explaining what it kept and skipped. It runs headless through Claude Code on a Windows schedule, with no one watching.

  1. DoneProject setup: master resume, preferences, a tracker and 10 real postings
  2. RunningDaily unattended search with a written report per run
  3. In progressPosting parser: every job as a validated record, with unknown facts left empty instead of guessed
  4. NextFit scorer measured against my own labels, then a tailoring skill, a tracker MCP server and an approval-gated apply step

The guardrails matter as much as the features:

  • The agent can read anything in the project but can only write inside its jobs folder. Every other tool is denied.
  • It never fills in, starts or submits an application. I click Submit.
  • Any work-authorization question comes back marked "needs my answer". It doesn't guess.
  • It only uses sources that allow automated access. No scraping.

Third scheduled run: 18 searches, 26 postings read in full, 12 saved, nothing submitted. Each saved role comes with a one-line reason and a list of gaps to check before applying.
Nov 22, 2026
First unattended run. An agent with no one watching needs an explicit tool allowlist, so the scheduled script names the few tools it may use and limits writes to one folder.
Nov 22, 2026
Strict structured output enforces the schema's shape but not every constraint. Length limits still need a check in code.
Nov 22, 2026
When a posting doesn't state a remote policy, "unknown" is the right answer. A confident guess is worse than an empty field.
